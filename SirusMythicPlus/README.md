**SirusMythicPlus** — аддон для просмотра Mythic+ статистики игроков прямо в клиенте Sirus.<br>
Он добавляет M+ информацию в обычный tooltip игрока и позволяет отдельно искать персонажей по нику, чтобы быстро оценить их прогресс и результаты.

## Возможности

### 📊 Mythic+ статистика в tooltip

При наведении на игрока можно увидеть:

- текущий сезон и неделю;
- рейтинг Mythic+;
- место в ладдере;
- максимальный закрытый ключ;
- список Mythic+ подземелий;
- лучший результат по каждому данжу;
- время прохождения и таймер подземелья, если сервер предоставляет эти данные.

Например:

> **Рейтинг М+:** 157  
> **Место в ладдере:** 4758  
> **Макс. ключ:** +12 Кузня Крови  
> **Время:** 44:18 / 45:00

### 🔎 Поиск игроков

В аддоне есть отдельное окно **«Поиск игроков Mythic+»**:

1. Вводите ник игрока.
2. Получаете список найденных персонажей с рейтингом и местом в ладдере.
3. Выбираете нужного игрока.
4. Справа открывается его Mythic+ статистика.

Можно быстро посмотреть:

- рейтинг;
- позицию в ладдере;
- лучший ключ;
- количество забегов;
- результаты по отдельным подземельям;
- время прохождения.
- Профиль игрока на https://sirusmythic.ru/;

По сути, это удобный способ проверить M+ прогресс игрока перед тем, как взять его в группу.

### ⚙️ Дополнительно

- обработка асинхронных ответов сервера;
- защита от ошибок и особенностей клиентского API Sirus; (не всегда, но спасает)
- обновление аддона через лаунчер Sirus.

## Установка

1. Скачайте последнюю версию:
   [**SirusMythicPlus.zip**](https://github.com/KataLoved/SirusMythicPlus/releases/latest/download/SirusMythicPlus.zip)
2. Распакуйте архив.
3. Переместите папку `SirusMythicPlus` в:
   `World of Warcraft Sirus\Interface\AddOns\`
4. Запустите игру и пользуйтесь.

## Совместимость

Аддон рассчитан на клиент **Sirus 3.3.5a (Interface 30300)**.

> Аддон тестировался на Live-версии клиента. Если вы используете другую ветку клиента и столкнулись с ошибкой — сообщите об этом, попробуем исправить.
